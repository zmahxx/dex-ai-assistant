# Dexter Dashboard

This dashboard is part of the Dexter desktop assistant. It was developed with Lovable under the project owner's direction and AI-assisted coding. UI source components based on shadcn/ui are credited in the root THIRD_PARTY_NOTICES.md.

The React application uses TanStack Start/Router and communicates with the local Dexter service through a same-origin server proxy. See the repository root README for architecture, configuration, and limitations.
